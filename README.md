# 🚀 Node.js & Express.js API with Auth0 Authentication  

This project is a **secure Node.js API** using **Express.js** and **Auth0 JWT authentication**. It includes **environment variable management**, **email sending via SMTP**, and **deployment to Railway or Render**.

---

## **📌 Features**
✅ Send mail with your token for authentication

✅ `/auth/user` only access user 

✅ `/auth/admin` only access admin 

✅ Authenticated and role based access with api

## ** Dependencies**
✅ Secure API authentication using **Auth0 (`express-oauth2-jwt-bearer`)**  
✅ Uses **JWT tokens** to protect API routes  
✅ **Environment variables** (`.env`) for managing sensitive data  
✅ **Email notifications** via **SMTP & Nodemailer**  
✅ Ready for **deployment** on **Railway / Render**  

---

## **Deployment**
 ### Deploy to Railway
Railway is a free hosting platform for Node.js apps.

Sign up on Railway → https://railway.app/

Click New Project → Deploy from GitHub

Select your repository.

Set up Environment Variables in Railway settings.

Click Deploy 🎉
